Política de privacidad

Última actualización: septiembre de 2026

Notas es una aplicación de uso personal para tomar y organizar notas. Esta página explica qué información gestiona la aplicación y cómo se usa.

Quién gestiona esta aplicación

Esta aplicación ha sido creada y es gestionada por un desarrollador independiente para uso personal. Puedes contactar a través de: tu-correo@ejemplo.com.

Qué datos se guardan y dónde

Todo el contenido que creas en la aplicación (notas, listas y las imágenes que adjuntas) se guarda directamente en tu propia cuenta de Google Drive, dentro de una carpeta creada por la aplicación exclusivamente para este fin. La aplicación no dispone de ningún servidor propio donde se almacenen tus datos: estos permanecen en tu cuenta de Google, bajo tu control en todo momento.

Adicionalmente, una copia de tus notas se guarda de forma local en el propio dispositivo (ordenador o teléfono) para que la aplicación funcione sin conexión a internet.

Acceso a Google Drive

La aplicación solicita permiso de acceso a Google Drive mediante el scope drive.file, que limita el acceso exclusivamente a los archivos que la propia aplicación crea. La aplicación no puede leer, modificar ni acceder a ningún otro archivo de tu Google Drive.

El uso que esta aplicación hace de la información recibida a través de las APIs de Google se ajusta a la Política de datos de usuario de los Servicios de API de Google, incluidos los requisitos de uso limitado.

Con quién se comparten los datos

No se comparten datos con terceros. No se usan datos con fines publicitarios ni comerciales. La aplicación no incluye ningún sistema de analítica, seguimiento ni recopilación de datos con fines estadísticos.

Cómo eliminar tus datos

Puedes eliminar tus notas en cualquier momento desde la propia aplicación, o borrando directamente la carpeta correspondiente desde tu Google Drive. Puedes revocar el acceso de la aplicación a tu cuenta de Google en cualquier momento desde la configuración de permisos de tu cuenta de Google.

Cambios en esta política

Esta política puede actualizarse ocasionalmente para reflejar cambios en la aplicación. La fecha de la última actualización aparece al principio de esta página.
